# Voice RAG Frontend

A modern frontend for a **Voice-based RAG (Retrieval-Augmented Generation) application**.

## 🚀 Features

* 🎙️ Voice-based interaction
* 🤖 AI-powered responses
* 📚 Retrieval-Augmented Generation (RAG)
* ⚡ Fast and responsive frontend
* 🔗 API integration
* 🧩 Modular React/TypeScript architecture

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* CSS
* Node.js

## 📦 Installation

```bash
npm install
```

## ▶️ Run Locally

```bash
npm run dev
```

Then open the local URL shown in the terminal.
